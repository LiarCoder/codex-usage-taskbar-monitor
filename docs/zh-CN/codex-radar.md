# CodexRadar 推荐

CodexRadar 是一个可选的实验性增强功能。Monitor 使用雷达站公开评分数据计算非个性化的模型与推理强度推荐。该功能默认关闭，不影响核心用量监控。

## 启用与使用

在“设置 > CodexRadar > 启用 CodexRadar”中开启功能。首次开启时，应用会先显示隐私提示；只有确认后才会向 CodexRadar 发送请求。

启用后，将鼠标停在小工具内容区域约 500 毫秒即可查看推荐。左侧拖动把手不触发提示。还可以通过菜单打开网站，或者在小工具内容区域快速三击直接打开。

## 推荐显示

提示中显示 Monitor 计算的日常与难题推荐。应用不再请求或展示站点自带推荐，相关接口的故障不会影响 Monitor 推荐的刷新状态。

| 显示项 | 选择方式 |
| --- | --- |
| 日常推荐 | 从最新已完成的四任务评测中筛选四项成绩完整、雷达分 ≥ 90 且费用、耗时有效的组合，按 `价格相对成本 ^ 0.7 × 时间相对成本 ^ 0.3` 选择最低者；成本相同时优先雷达分 |
| 难题推荐 | 在上述组合中筛选四题 API 等价估算总额 ≤ $9、总耗时 ≤ 30 分钟的组合；以 $8 和 30 分钟为目标，雷达分相差至少 10 分时选择更高者，否则选择日常成本更低者 |

应用读取雷达站公开的[四任务评测 JSON](https://codexradar.com/data/codex-four-task-results.json)，仅接受已完成发布且评分协议为 `codex-four-weighted-150-v2` 的数据。Combined、Pompeii、Pelican、Candy 四项分别占 60、45、22.5、22.5 分，总分为 150；不套用旧版 IQ 的 Wilson 置信界。费用为四题 API 等价估算之和，耗时为四题模型执行时间之和，不包含评分模型耗时，也不是订阅扣费或实际支出。任一项缺少有效成绩、费用或耗时的组合不参与推荐；缺失值不补零。数据代表最新已完成的评测轮次，不混入正在进行轮次的部分成绩。

Monitor 的当前评分接口不可用时，回退到旧版原始效率接口；旧版数据显示 IQ，日常与难题排序使用 95% Wilson 下置信界得到的可信 IQ。不会将已归档的静态 IQ 快照作为当前数据。社区数据不会根据你的账户实际可用模型进行筛选，因此推荐组合可能无法在当前账户中使用。

## 刷新、缓存与故障

- Monitor 推荐刷新成功后约每小时更新一次；菜单中的手动刷新有 60 秒冷却时间
- 只缓存 Monitor 派生推荐、评分口径、缓存时间和请求校验值，完整响应不会原样保存；支持 ETag 条件请求，抓取或校验失败时保留有效缓存并重试
- 升级到四任务数据源时清除旧评分口径的推荐、请求校验值和失败退避，启动后立即刷新
- 缓存最长保留 24 小时；刷新失败时会标记缓存可能过期，并逐步延长重试间隔
- CodexRadar 请求失败、数据过期或接口格式不兼容时，核心 Codex 用量轮询仍会继续工作

应用不会向 CodexRadar 发送 Codex Token、用量数据或项目内容。完整联网说明见[诊断与隐私](diagnostics-and-privacy.md)。
